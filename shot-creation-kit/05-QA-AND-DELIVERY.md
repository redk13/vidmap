# QA والتسليم — قائمة تحقق إلزامية

## قبل GitHub

- [ ] قرأت طلب المستخدم الحالي والممنوعات، ولم أفترض نجاح نسخة قديمة.
- [ ] العينة صغيرة وليست إنتاجًا كاملًا غير مصرح به.
- [ ] كل الصور والخامات موجودة محليًا ومصادرها وتراخيصها موثقة.
- [ ] النصوص تخص الموضوع، وليست بقايا عينة سابقة.
- [ ] سكربت المستخدم، إن وُجد، لم يتغير حرفًا.
- [ ] syntax والحزمة والأصول سليمة؛ لم أرندر محليًا.
- [ ] التكوين وfps وعدد الإطارات ونطاق workflow متطابقة.
- [ ] لا مفتاح في الملفات أو Git أو STATUS أو logs.

## بعد GitHub

- [ ] run انتهى `completed/success`، وartifact نُزّل وفُك فعليًا.
- [ ] الفيديو ليس صفرًا، ومدته وذيله سليمان.
- [ ] الدقة وfps وعدد الإطارات والحجم وMD5 مسجلة.
- [ ] راجعت بداية ووسط ونهاية وكل مرحلة حركة، لا صورة ثابتة واحدة فقط.
- [ ] النص واضح ولا تداخل ولا اهتزاز أو حركة تخفي العيوب.
- [ ] أداء القارئ طبيعي جدًا وقريب من البشري؛ لا نبرة AI/روبوت أو قراءة مسطحة، وقد فُحصت عينة قصيرة قبل إكمال التعليق.
- [ ] الصوت كامل، ولا فجوات صامتة غير مقصودة.
- [ ] لا تغير هوية الصوت أو سرعته أو مستواه بشكل مصطنع بين المقاطع؛ تنوع النبرة الطبيعي حسب المعنى مطلوب.
- [ ] لا توقف وانطلاق أو قطع كلمات عند الوصلات.
- [ ] الموسيقى هادئة ومستمرة، وكل SFX متزامن وله معنى.
- [ ] عند استئناف توليد بعد حد، فُحصت وصلة الاستئناف تحديدًا.

## العرض والأرشفة

- [ ] اسم ملف العينة جديد، والنسخة المعروضة هي التي فُحصت.
- [ ] لم أكتب «معتمدة» قبل موافقة المستخدم.
- [ ] بعد الاعتماد: بطاقة + فيديو + كود + أصول + صوت + تراخيص + تشغيل مستقل.
- [ ] أنشأت مجلد اللقطة بالاسم نفسه في مكتبة نيش طوكيو ومكتبة 05 داخل حقيبة 06.
- [ ] رفعت **نسخة فعلية كاملة** من كل ملف إلى المجلدين؛ لا اختصارات ولا ZIP وحده، ولم أحذف الأصل.
- [ ] تحققت في المكتبتين من البنية والأسماء والأعداد وقراءة البطاقة وحجم/MD5 للفيديو.
- [ ] سجلت المستودع وcommit وrun وartifact وروابط Drive للمكتبتين، وليس المفتاح.
- [ ] نظفت مجلدات العمل بعد تأمين النسختين، وحدثت STATUS.
