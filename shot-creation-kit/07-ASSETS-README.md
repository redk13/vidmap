# تجهيز الصور والأصول

## ما يعطيه المستخدم

- ضع الصور والمراجع التي يعطيها المستخدم في مجلد عمل واضح، وافحصها قبل بناء الحركة.
- انسخ الأصول التي يحتاجها Remotion إلى `public/` بأسماء ثابتة؛ لا تجعل الرندر يعتمد على روابط خارجية.
- إذا كانت الصورة مرجعًا للأسلوب فقط، لا تدمجها أو تشتق منها عندما يمنع المستخدم ذلك.

## ما يجب فحصه

1. الأبعاد والوضوح وقناة alpha والحواف.
2. النصوص الموجودة داخل الصورة: هل هي مطلوبة أم يجب استبدالها بمحتوى الموضوع؟
3. القص: افحص العنصر فوق خلفية ملوّنة وبأكبر مقياس سيظهر به.
4. المصدر والمؤلف والرابط والترخيص وتاريخ الوصول، وأي تعديل أجريته.
5. أسماء الملفات والمسارات داخل الكود، وحجم الحقيبة.

## أصول جديدة لكل موضوع

لا تستخدم نصوص طوكيو أو عناوين العينات السابقة كمحتوى نهائي. أنشئ أو جهّز الكتابة والخامات التي تخدم سكربت المستخدم ومعلوماته، مع بقاء الأسلوب الحركي المقصود فقط.

## ملف التراخيص

أنشئ `licenses.md` وسجّل فيه كل أصل، حتى الأصول المولّدة أو الصوت المصنوع برمجيًا. اكتب بوضوح ما هو أصلي وما هو مستمد وما هو مرخص خارجيًا. لا تضع أي مفتاح GitHub أو سر في هذا الملف.
