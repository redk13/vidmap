# حقيبة صناعة اللقطات الجديدة — ابدأ هنا

هذه الحقيبة **مستقلة تمامًا عن مكتبة اللقطات المعتمدة**. مكتبة الاستخدام تشرح كيف تُدخل اللقطات في فيديو الخرائط؛ أما هذه الحقيبة فتشرح **كيف نصنع لقطة جديدة من الصفر** بالمراحل والفحوص والقوالب.

## ما الذي سيعطيه المستخدم؟

قد يعطيك صورًا أو مراجع أو خامات أو وصفًا لحركة يريدها، وقد يعطيك نصًا مؤقتًا للعينة. وسيعطيك عند الحاجة إلى الرندر:

- مفتاح GitHub خاصًا بهذه المهمة: `GH_TOKEN`.
- اسم المستودع الذي يجب استعماله: `GH_REPO=OWNER/REPOSITORY`.
- الفرع إن كان محددًا.

هذه مدخلات المهمة، وليست مفتاحًا أو مستودعًا من مشروعنا السابق. اتبع `02-GITHUB-USER-REPO.md` ولا تطبع السر أو تحفظه.

## ترتيب القراءة والتنفيذ

1. اقرأ هذا الملف ثم `01-CREATION-STAGES.md`.
2. اقرأ `02-GITHUB-USER-REPO.md` قبل استعمال المفتاح أو المستودع.
3. اقرأ `03-AUDIO-RULES.md` قبل توليد أي صوت.
4. جهّز الأصول وفق `07-ASSETS-README.md`، ووثّق مصدر وترخيص كل خامة.
5. استخدم قوالب التشغيل المرفقة، ونفّذ فحوص `05-QA-AND-DELIVERY.md`.
6. دوّن الحالة في نسخة من `06-STATUS.template.md`، ولا تكتب المفتاح فيها.
7. عند الاعتماد، أنشئ بطاقة من `04-SHOT-CARD-TEMPLATE.md` وأرشف العينة والكود والأصول والصوت والتراخيص.

## قواعد لا يجوز تجاوزها

- **ممنوع رندر الفيديو داخل مساحة العمل أو الساندبوكس. الرندر على GitHub Actions فقط، في المستودع الذي يعطيه المستخدم.** الفحوص المحلية الخفيفة للكود والصور والصوت مسموحة.
- ابدأ بعينة صغيرة تثبت الفكرة؛ لا إنتاج كامل قبل اعتماد المستخدم.
- الصور والنصوص المؤقتة في العينة ليست قالبًا للمحتوى النهائي.
- إذا أعطى المستخدم سكربتًا فهو مجمّد حرفيًا، والتعليق الصوتي يقرأه فقط.
- لا تغيّر الصوت ولا تترك فجوات صامتة غير مقصودة أو توقفًا وانطلاقًا بين المقاطع.
- عند بلوغ حد التوليد، توقف واطلب المتابعة من أول مقطع ناقص؛ لا تسلّم صوتًا ناقصًا.
- الموسيقى هادئة، وكل SFX له معنى وحدث بصري؛ لا مؤثرات عشوائية.
- لا تقل إن الرندر نجح قبل نجاح GitHub run ووجود الفيديو وفحصه.

## القوالب المرفقة

- `shotlab.yml`: workflow يدوي للرندر على GitHub.
- `package.json` و`package-lock.json`: بيئة Remotion مستقلة بلا Three.js.
- `index.ts` و`Root.tsx` و`PipelineCheck.tsx`: اختبار pipeline صغير فقط، وليس لقطة فنية جاهزة.
- `08-PROMPT-NEW-CHAT.md`: مطالبة جاهزة لبدء محادثة جديدة بهذه الحقيبة.

## تركيب قوالب المشروع

ضع `package.json` و`package-lock.json` في جذر المشروع. ضع `index.ts` و`Root.tsx` و`PipelineCheck.tsx` داخل `src/`، وضع `shotlab.yml` في `.github/workflows/shotlab.yml`. أنشئ `public/` للأصول الفعلية. التكوين المرفق `pipelineCheck` مدته 30 إطارًا لاختبار البيئة فقط؛ أضف تكوين اللقطة الجديدة بعد ذلك وحدّث مدخلات workflow بما يطابق مدته.

لا تحتاج هذه الحقيبة إلى مفتاح مكتوب داخلها، ولا إلى مستودعنا السابق. المستخدم يعطي المفتاح والمستودع عند التنفيذ.
